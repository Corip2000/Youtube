# ShortsOffline (Android)

Нативное приложение: качает случайные шортсы вместе с топ-100 комментариев,
даёт смотреть их без интернета, стирает просмотренное и показывает при выходе,
сколько места освободилось. Никакого сервера — yt-dlp и Python лежат внутри APK.

## Сразу о неприятном

YouTube Data API отдаёт только метаданные — заголовки, лайки, комментарии.
Видеофайлы достаёт встроенный **yt-dlp**, а это вне правил YouTube. Штука для
себя: не для Google Play и не для раздачи скачанного.

APK получается тяжёлым (~50 МБ на arm64), потому что внутри Python и ffmpeg.

## Шаг 1. Ключ Google Cloud

Минимум нужен **API-ключ** — этого хватает на случайные шортсы, лайки и комменты.

1. [console.cloud.google.com](https://console.cloud.google.com/) → новый проект.
2. **APIs & Services → Library** → **YouTube Data API v3** → **Enable**.
3. **Credentials → Create credentials → API key** → скопируй.
4. В приложении: **Ключи** → вставь в поле «API key» → **Сохранить**.

Всё, можно качать.

### Вход в Google (необязательно)

Нужен только ради режима «Мои подписки». Требует, чтобы SHA-1 ключа подписи APK
совпадал с тем, что записан в Google Cloud — это главная возня, поэтому и сделано
отдельно.

1. Узнай SHA-1 своего ключа:
   ```bash
   keytool -list -v -keystore ~/.android/debug.keystore \
     -alias androiddebugkey -storepass android
   ```
2. **OAuth consent screen** → тип **External**, добавь свой аккаунт в **Test users**.
3. **Credentials → OAuth client ID → Android**:
   - package name: `ru.corip.shortsoffline`
   - SHA-1: из шага 1
4. Скопируй client ID → в приложении **Ключи** → поле «OAuth client ID».

> Если собираешь через GitHub Actions без своего keystore, ключ подписи будет
> каждый раз новый и SHA-1 не совпадёт. Тогда вход в Google работать не будет —
> пользуйся API-ключом. Как сделать стабильную подпись — ниже.

## Шаг 2. Сборка

**Android Studio.** Открой папку проекта, дай Gradle подтянуть зависимости,
жми Run. Первая сборка долгая: тянется ~150 МБ библиотек.

**Без ПК, через GitHub Actions.** Залей проект в репозиторий — workflow
`.github/workflows/build-apk.yml` соберёт APK и положит в артефакты запуска.
Скачиваешь прямо с телефона и ставишь.

Чтобы вход в Google работал и при облачной сборке, сделай свой ключ один раз:

```bash
keytool -genkey -v -keystore keystore.jks -keyalg RSA \
  -keysize 2048 -validity 10000 -alias shorts
base64 -w0 keystore.jks     # содержимое → секрет KEYSTORE_BASE64
```

Добавь в **Settings → Secrets → Actions** репозитория: `KEYSTORE_BASE64`,
`KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`. Workflow сам напечатает SHA-1
в логе — его и вбей в Google Cloud.

## Как пользоваться

**Скачать шортсы** → источник и количество (1–50) → **Найти шортсы**.
Приложение соберёт кандидатов, отсеет горизонтальные и посчитает вес каждого.
Покажет список с размерами и общий вес партии — жмёшь **Скачать**, если устраивает.

**Смотреть шортсы** — вертикальный плеер:
- свайп вверх — следующее, свайп вниз — предыдущее;
- тап — пауза;
- 💬 — комментарии, отсортированные по лайкам;
- «назад» — закрыть комментарии, ещё раз — выйти в меню.

Досмотрел до конца (или больше 90 %) и ушёл дальше — файл стирается с диска.
Перемотал назад к недосмотренному — останется. При выходе в меню выпадает чек:
сколько удалено и сколько места освободилось.

## Что где лежит

Видео: `Android/data/ru.corip.shortsoffline/files/videos/` — на каждое видео
`.mp4`, превью `.jpg` и комментарии `.json`. Папка приложения, разрешений не
просит и чистится при удалении приложения.

Индекс и статистика — во внутреннем хранилище приложения.

## Про комментарии и квоту

API отдаёт максимум 100 комментариев верхнего уровня за раз и до 5 ответов
инлайном. Приложение берёт эти 100, сортирует по лайкам и у 25 самых
залайканных дотягивает ответы до 10 отдельными запросами. Дотягивать у всех ста
нельзя: это 100 единиц квоты на одно видео, а в сутки их 10 000.

Расход на партию из 20 шортсов — примерно 500–800 единиц. Режим «Мои подписки»
дешевле раз в десять, потому что обходится без `search.list` (100 единиц за вызов).
Квота сбрасывается в 10:00 МСК.

Аватарки не качаются — вместо них кружки с буквой. Иначе на видео со ста
комментариями это сто лишних файлов, которые всё равно не отрисуются без сети.

## Если что-то сломалось

**Скачивание падает на всех видео.** YouTube регулярно ломает старые версии
yt-dlp. В меню есть **Обновить yt-dlp** — жми, оно подтянет свежий бинарник.

**«Вертикальных шортсов в выдаче не оказалось».** Затравка поиска выбирается
случайно, иногда попадаются одни горизонтальные ролики. Просто повтори поиск.

**«Дневная квота кончилась».** Жди 10:00 МСК или переключись на подписки.

**Вход в Google не проходит.** Либо аккаунт не в Test users, либо SHA-1 не тот.
Проверь, каким ключом подписан установленный APK.

**Не собирается на `updateYoutubeDL`.** В некоторых версиях библиотеки метод
требует второй аргумент — тогда в `Downloader.kt` замени вызов на
`updateYoutubeDL(context, YoutubeDL.UpdateChannel.STABLE)`.

**Нужна поддержка старых 32-битных телефонов.** В `app/build.gradle.kts` добавь
`"armeabi-v7a"` в `abiFilters` — APK потяжелеет вдвое.
